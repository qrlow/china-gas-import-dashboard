What the Optimizer Does

  1. Observe the editable monthly TTF forward curve.
  2. Test feasible inventory moves on a 10 GWh grid.
  3. Account for injection and withdrawal losses and variable costs.
  4. Choose the highest-value path that respects capacity, rate, and ending-inventory constraints.

How to Read the Result

Intrinsic value is the cash value available from the entered forward curve if the nominated schedule can be locked in. It is not a forecast or the full value of storage optionality.

A desk model would next add daily products, inventory-dependent ratchets, booked capacity fees, financing, outages, bid-offer spreads, and stochastic re-optimization.
